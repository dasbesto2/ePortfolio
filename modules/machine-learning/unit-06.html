Unit 6 — Clustering with Python

LO2 Dataset applicabilityLO3 Applying ML techniquesLO4 Team & professional practice

Clustering task

K-means clustering applied to three different datasets: Iris, Wine and Weather (weatherAUS). Each has its own Python script, linked from its section below.

Iris

The standard Iris dataset with the columns sepal_length, sepal_width, petal_length, petal_width and species. What I did:

  • Removed the non-numeric species column for clustering.
  • Ran K-means (including K = 3) and compared the K = 3 clusters against the actual species labels.

What the script does

  1. Drops the species column before clustering — it is text, and K-means needs numeric features since it computes Euclidean distances. The 4 remaining columns are standardised and used for clustering.
  2. Elbow method runs K = 1–10 to show inertia dropping off, confirming K = 3 is a reasonable choice.
  3. Fits K-means with K = 3 as required.
  4. Compares clusters to true species via a crosstab, Adjusted Rand Index and Normalized Mutual Information.

This matches the well-known pattern in the Iris dataset: setosa is linearly separable from the other two species based on petal measurements, while versicolor and virginica have some natural overlap in feature space, making them harder for an unsupervised method to fully distinguish.

Wine

Excellent results — very strong agreement between clusters and true labels.

What the script does

  1. Drops the Wine column (the true class label 1/2/3) before clustering — it is a category, not a chemical measurement, so keeping it in would let the model "cheat".
  2. Standardises the 13 remaining chemical features — critical here since Proline ranges into the hundreds and thousands while Hue is close to 1; without scaling, K-means would be dominated entirely by Proline.
  3. Elbow method across K = 1–10 to see where added clusters stop reducing inertia much (supports K = 3).
  4. Fits K-means with K = 3 as required.
  5. Compares clusters to the true wine labels.

This is a much cleaner separation than the Iris case — the three cultivars are strongly distinguishable by their chemical profiles (alcohol, flavanoids, colour intensity, proline, etc.), so unsupervised K-means recovers the true grouping almost perfectly, with only 6 wines out of 178 misassigned.

Weather

What the script does

  1. Removes non-numeric columns — RainToday and RainTomorrow are Yes/No text labels, not measurements a Euclidean distance can be computed on, so they are excluded from clustering. (RainTomorrow is kept aside purely to colour a reference plot afterwards, since this dataset has no ground-truth cluster labels like species or wine class.)
  2. Drops rows with missing values — from 145,460 rows to 120,381 complete rows, since K-means cannot handle NaNs.
  3. Standardises the 12 numeric weather features (temperature, rainfall, humidity, wind, pressure) since they are on very different scales.
  4. Runs K-means for K = 2 through K = 6, tracking inertia (elbow) and silhouette score for each.
  5. Visualises every K with 2-D scatter plots using PCA (since 12 features cannot be plotted directly) — all six panels side by side, plus a reference panel coloured by RainTomorrow.

  • Silhouette score peaks at K = 2 (0.231), meaning the data most naturally splits into two broad groups — likely something like "cooler/humid" vs. "warmer/dry" weather regimes, visible as a clean vertical split in the K = 2 panel.
  • As K increases, the clusters just subdivide these two broad regions further rather than revealing genuinely new structure — inertia keeps dropping (it always does), but silhouette drops off, meaning the extra splits are less well separated.
  • Unlike Iris and Wine, there is no true "answer key" here (no species or wine-class column), so this is a purely exploratory result rather than something to validate against ground truth.
  • The reference panel comparing PC1/PC2 to RainTomorrow shows rainy days leaning toward the upper region (higher PC2 — likely correlating with humidity), but there is no clean separation — rain is not strongly determined by these same-day readings alone, which makes sense since predicting tomorrow's rain is a genuinely harder problem than clustering today's conditions.
