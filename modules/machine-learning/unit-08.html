Unit 8 — Training an Artificial Neural Network

LO2 Dataset applicabilityLO3 Applying ML techniques

Two activities this unit: a hands-on test of gradient descent's learning-rate sensitivity, and a small recommender-system case study using SHAP for explainability.

Gradient descent & cost function

Source article: Mayo, M. (2017) Neural Network Foundations, Explained: Updating Weights with Gradient Descent & Backpropagation, KDnuggets.

IterationsLearning rateFinal costObservation
1000.08 (default)0.0041Close to optimal (m≈2.04, b≈2.85) but not fully converged
10000.08~1.5e-24Fully converged to the true m=2, b=3
1000.01 (too small)0.48Too slow — cost barely drops in 100 steps
1000.5 (too large)6.4e+206Diverges — cost explodes instead of shrinking

The learning rate is a critical hyperparameter: too small wastes iterations, too large overshoots the minimum so badly the cost grows without bound. The default (100 iterations, lr 0.08) gets close but needs ~300–400 iterations to fully settle for this dataset.

MovieLens 100K — matrix factorisation + SHAP

📄 notebooks/Unit08_movielens_matrix_factorisation_shap.ipynb

This is the notebook I made for the proposed exercise.

  1. Loaded and validated MovieLens 100K (100,000 ratings, 943 users, 1,682 movies; sparsity 0.937), split 80/10/10 by time.
  2. Baselines: global mean (test RMSE 1.140), regularised bias model (1.045).
  3. Matrix factorisation (SGD, 32 latent factors) overfits past epoch 5 (best validation RMSE 1.030); early-stopped test RMSE 1.037, MAE 0.835.
  4. Ranking at K=10: precision 0.168, recall 0.058, NDCG 0.328 — only 3% of the catalogue gets recommended.
  5. Diagnostics: cold users RMSE 1.20 vs. warm users 1.02; recommended movies are far more popular on average (182 vs. 50 ratings) than the catalogue as a whole.
  6. A Ridge surrogate reproduces the MF predictions (RMSE 0.015) closely enough that SHAP on the surrogate is a fair stand-in for explaining the original model. Biases account for ~74% of SHAP importance; the latent factors add little readable meaning — the model is closer to "popularity + rating habit" than personal taste.
